# j-256 Homebrew Tap

Homebrew packages for j-256 projects.

## Install QLOmni

```sh
brew install --cask j-256/tap/qlomni
```

QLOmni adds Quick Look previews for text files that macOS does not recognize. See the [QLOmni repository](https://github.com/j-256/qlomni) for supported formats, source code, and release details.
